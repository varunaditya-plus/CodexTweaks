## Features

- **Use OpenAI API Key:** Get double usage in Codex by using an OpenAI API key from the OpenAI Developer Platform, and easily switch between it and your account, with all your projects saved. This gets double usage due to [included API credits on Pro plans](https://developers.openai.com/api/docs/guides/chatgpt-api-credits).

## Installation & Setup

1. Open the [latest release](https://github.com/varunaditya-plus/codextweaks/releases/latest)
2. Download the file for your system and run it
2. Open Codex Tweaks from the menu bar and choose **Settings**.
3. Paste an API key from [platform.openai.com/api-keys](https://platform.openai.com/api-keys) and click **Save**. The key is checked with OpenAI first, then Codex Tweaks offers to use it in Codex.
4. To go back to your ChatGPT account, choose **Switch to OpenAI account** and sign in on Codex's sign-in screen.
